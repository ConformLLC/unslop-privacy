# conformllc.github.io

Public site for Conform LLC, served by GitHub Pages at https://conformllc.github.io

- Holds only public pages, like product privacy policies
- No product code lives here

## Pages

- `index.md`: home page
- `unslop/privacy/index.md`: Unslop privacy policy. Keep in sync with `PRIVACY.md` in the private `unslop` repo

## Adding a Product

- Add a folder named after the product, like `hoo-rx/privacy/index.md`
- Link it from `index.md`
